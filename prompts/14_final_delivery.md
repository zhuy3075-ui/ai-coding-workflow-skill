# 交付文档与最终验收提示词

请使用 `$ai-coding-workflow` 的「生成交付文档」命令。

请读取当前项目文档、代码状态和 MVP 总验收报告，创建或更新：

- `README.md`
- `docs/USER_GUIDE.md`
- `docs/DELIVERY.md`
- `docs/CHANGELOG.md`

完成后继续使用「最终交付验收」命令。

要求：

1. 不新增功能。
2. 不执行后续版本任务。
3. 检查 README、USER_GUIDE、DELIVERY、CHANGELOG、PRD/SPEC/TASKS/PROGRESS、构建、测试、核心流程和已知问题。
4. 输出正式交付结论和给甲方的交付说明。
